🐾 Pata Viva — ONG Connect

Projeto acadêmico de desenvolvimento web para a Pata Viva, uma organização fictícia voltada à proteção, ao cuidado e ao bem-estar animal.

A plataforma tem como objetivo apresentar iniciativas da ONG, divulgar projetos e facilitar o contato e o cadastro de pessoas interessadas em contribuir com a causa animal.
💻 Tecnologias utilizadas

- HTML5: estruturação semântica e organização do conteúdo das páginas.
- CSS3: estilização, responsividade, layouts e identidade visual, com uso de Flexbox, Grid e variáveis CSS.
- JavaScript: implementação de funcionalidades e interações no lado do cliente.
- Git e GitHub: controle de versão, organização do trabalho em equipe e gerenciamento de branches e Pull Requests.

  🤖 Utilização de Inteligência Artificial

  Ferramentas de Inteligência Artificial foram utilizadas como apoio ao processo de desenvolvimento, principalmente para:

- Esclarecimento de conceitos e dúvidas técnicas.
- Consulta de boas práticas de HTML, CSS e JavaScript.
- Apoio na identificação e correção de problemas.
- Sugestões de organização, acessibilidade e melhoria do código.
  A IA foi utilizada como ferramenta auxiliar, não como substituta do desenvolvimento, das decisões técnicas ou da validação realizada pelos integrantes.

🚀 Como executar o projeto

1. Clone o repositório:
   git clone https://github.com/matheusfonsecacmyk/ong-connect-entrega-2.git
2. Entre na pasta:
   cd ong-connect-entrega-2
3. Abra o arquivo index.html no navegador ou utilize a extensão Live Server no Visual Studio Code.
